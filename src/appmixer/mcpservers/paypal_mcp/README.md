PayPal MCP Server
-------------------------------

Allows you to integrate with PayPal APIs through function calling. This protocol supports various tools to interact with different PayPal services. (@paypal/mcp 0.3.2). Documentation: <a target=_blank href='https://github.com/paypal/agent-toolkit/tree/main/modelcontextprotocol'>https://github.com/paypal/agent-toolkit/tree/main/modelcontextprotocol</a>

NPM Repository
--------------

@paypal/mcp@0.3.2

Generate Command
----------------

appmixer @paypal/mcp /tmp/mcpservers/src/appmixer/mcpservers/ --verbose --replace --label PayPal --desc Allows you to integrate with PayPal APIs through function calling. This protocol supports various tools to interact with different PayPal services. --icon https://upload.wikimedia.org/wikipedia/commons/b/b7/PayPal_Logo_Icon_2014.svg --env PAYPAL_ACCESS_TOKEN,PAYPAL_ENVIRONMENT --scriptArgs --tools all --docs https://github.com/paypal/agent-toolkit/tree/main/modelcontextprotocol
